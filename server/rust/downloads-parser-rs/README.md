# series-radar-downloads-rs

Rust port of the Film2Media HTML parser in `series_radar/downloads.py`, bridged
with PyO3. Generated by `rust-anything`, then tuned by hand.

## Functions

- `fingerprint` (`series_radar/downloads.py:67`)
- `elements` (`series_radar/downloads.py:137`)
- `parse_movie_page` (`series_radar/downloads.py:216`)
- `parse_series_page` (`series_radar/downloads.py:290`)

Only the two page parsers are used in production: `series_radar/fastparse.py`
loads this module when present and `downloads.py` dispatches
`parse_series_page` / `parse_movie_page` to it. If the module is missing, fails
to import, or raises during a parse, the pure-Python implementation runs
instead. `SERIES_RADAR_PARSER=python` forces the Python path;
`SERIES_RADAR_PARSER=rust` makes a missing module an error.

## Build and ship

```sh
./server/build-native.sh   # cargo build --release -> server/series_radar_downloads_rs/
```

`server/deploy.sh` and `.github/workflows/deploy-api.yml` run that script and
ship the resulting package next to `series_radar/`. The package is ignored by
git; the source in this directory is committed.

## Characterization loop

Run from `server/` (the config's `root` is `.`):

```sh
rust-anything record rust/downloads-parser-rs
rust-anything build rust/downloads-parser-rs
rust-anything diff rust/downloads-parser-rs
rust-anything bench rust/downloads-parser-rs
rust-anything gate rust/downloads-parser-rs
```

`cases.jsonl` holds the recorded behavior of the Python original, including
real Film2Media pages, and must keep matching: `diff` and `gate` are the
contract for changing `src/port.rs`.
